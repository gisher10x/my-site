# האתר האישי של סער גישר

האתר מציג היכרות קצרה, רקע מקצועי, הסבר בשפה פשוטה על מה שאני עושה, וקישורים ליצירת קשר.
הוא מיועד לאנשים שרוצים להכיר אותי ואת העבודה שלי.

לאתר יש מצב בהיר ומצב כהה, וטופס יצירת קשר שבודק את השדות ושולח את ההודעה במייל דרך השירות FormSubmit. הוא מותאם למחשב ולטלפון.

## איך פותחים

1. מורידים את המאגר (Download ZIP) או משכפלים אותו עם `git clone`.
2. פותחים את הקובץ `index.html` בכל דפדפן.

אין צורך בהתקנה.

## מבנה הפרויקט

- `index.html` – התוכן והמבנה של העמוד.
- `style.css` – העיצוב של העמוד, כולל מצב כהה והתאמה למסכי טלפון.
- `script.js` – בדיקת השדות בטופס יצירת הקשר ושליחתו דרך FormSubmit, המעבר בין מצב בהיר לכהה, ואנימציות הגלילה.
- `Images/` – התמונות של האתר: תמונת הפרופיל והאיור.
